# Contributing to ShiftFlow

Thank you for your interest in contributing to ShiftFlow Workforce Management!

## Development Guidelines

1. **Code Standards**:
   - Write clean, modern ES module JavaScript / React.
   - Do not commit sensitive `.env` files or credentials.
   - Always run the test suite before submitting pull requests.

2. **Branching Strategy**:
   - `main`: Production-ready release branch.
   - `develop`: Integration branch.
   - Feature branches: `feature/feature-name` or `fix/issue-description`.

3. **Running Checks Locally**:
   ```bash
   npm run build
   npm test
   ```
